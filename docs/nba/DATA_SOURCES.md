# NBA data sources

The NBA explorer is a static 2025–26 regular-season snapshot generated by
`src.ftg.build_nba_site`.

- Player season totals originate from the [NBA Stats API](https://www.nba.com/stats/players/traditional?PerMode=Totals&Season=2025-26). The reproducible build uses the public CSV export maintained by [EasySportsApps](https://github.com/EasySportsApps/nba_api_25_26_data); the upstream scripts identify the NBA API as their source.
- Player identities and recorded birthplace entities are joined through the NBA.com player ID property in [Wikidata](https://www.wikidata.org/). Wikidata structured data is available under CC0.
- Population-normalized H3 cells use 2025 estimates from [WorldPop Global 2](https://hub.worldpop.org/project/categories?id=3), available under CC BY 4.0. Cells with fewer than two players or fewer than 100,000 residents are visually muted and labelled as unstable.
- Country boundaries use the same Natural Earth-derived GeoJSON bundled with the football explorer.
- CARTO and OpenStreetMap provide the interactive base map and are attributed in the map controls.

Birthplace describes the recorded place of birth. It does not imply nationality,
development pathway, academy, residence or international eligibility. Unresolved
players remain visible in the About data view and are never assigned a guessed
location.

No NBA or team logos are included. This project is independent and is not
affiliated with or endorsed by the NBA.
