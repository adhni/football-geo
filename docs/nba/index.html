    Resolution method

    Official ID first.
    Geography second.

    1. Start with every player recorded by the NBA Stats API.
    2. Match the NBA.com player ID in Wikidata.
    3. Resolve the recorded birthplace and coordinates.
    4. Keep every missing coordinate visible for QA.

    A reproducible season snapshot.
