    Cohort method

    One athlete.
    One entry per event.

    1. Keep athletes with an official result other than DNS.
    2. Deduplicate heats, semifinals and finals into one event entry.
    3. Count combined events once, not once per discipline.
    4. Use named relay lineups from each round.
